# Briefing do cliente — formulário para preencher

Copie este arquivo para `design/briefing-preenchido.md` e responda o que souber.

**Três coisas antes de começar:**

1. **Deixar em branco é permitido.** O que faltar vai virar uma pergunta única no fim, junto com
   todas as outras. Você não vai ter que ligar para o cliente cinco vezes.
2. **Não invente e não arredonde.** Se não tem certeza do número do WhatsApp, escreva
   `não confirmado` em vez de escrever um número parecido. Telefone errado é site que não funciona.
3. **Copie exatamente como o cliente escreve.** O jeito que ele chama o serviço dele é o jeito
   certo. "Banho e tosa" não vira "estética animal" porque soa melhor.

Quando terminar, avise que está pronto. O resto acontece sozinho até você precisar colar prompts
no ChatGPT.

## 1. Quem é a empresa — sem isso não dá para começar

| Campo | Exemplo preenchido | Sua resposta |
|---|---|---|
| Nome exato, como está no logo | `Santa Lúcia Clínica Veterinária` | |
| Como as pessoas chamam no dia a dia | `Santa Lúcia` | |
| O que a empresa faz, em uma frase | `Clínica veterinária 24h com pet shop e estética animal` | |
| Cidade | `Caxias do Sul` | |
| Estado | `RS` | |
| Bairro | `Santa Lúcia` | |
| Atende que região? | `Caxias do Sul e cidades vizinhas` | |
| Ano em que abriu | `2015` | |

> Por que a cidade importa tanto: ninguém pesquisa "veterinário". Pesquisa "veterinário 24h em
> Caxias do Sul". Sem a cidade escrita na página, o Google não mostra o site para essa busca.

## 2. Como falar com a empresa — sem isso não dá para começar

| Campo | Exemplo preenchido | Sua resposta |
|---|---|---|
| Telefone fixo | `(54) 3025-2223` | |
| **WhatsApp, com DDD** | `(54) 99999-1234` | |
| É o mesmo número do fixo? | `Não, é um celular separado` | |
| E-mail | `contato@empresa.com.br` | |
| Rua e número | `R. Jacob Luchesi, 3230` | |
| Complemento | `Loja 2` | |
| CEP | `95032-000` | |

> **O WhatsApp é o botão mais importante da página.** Quase sempre é um celular diferente do fixo
> — por isso perguntamos os dois. Se você mandar só um número e ele for o fixo, o botão principal
> do site vai abrir uma conversa que ninguém lê.
>
> **O CEP não é frescura.** É ele que faz o mapa acertar a quadra e o Google entender que é um
> negócio local de verdade.

## 6. Internet e documentos — a página fica pior sem isso

| Campo | Exemplo preenchido | Sua resposta |
|---|---|---|
| Já tem domínio comprado? | `Não` | |
| Se sim, qual? | `www.empresa.com.br` | |
| Se não, quer comprar qual? | `santaluciavet.com.br` | |
| Instagram (@) | `@santaluciavet` | |
| Facebook | `facebook.com/santaluciavet` | |
| Outras redes | `YouTube: @santaluciavet` | |
| Site atual, se existe | `www.santalucia.vet.br` | |
| CNPJ | `12.345.678/0001-90` | |
| Registro do conselho (CRMV, CRO, CREA, OAB…) | `CRMV-RS 1234` | |
| Nome do responsável técnico | `Dra. Fulana de Tal` | |

> **Domínio:** sem um endereço próprio, o site sai com um endereço da Vercel
> (`nome-do-projeto.vercel.app`). Funciona, mas trocar depois obriga a refazer configuração e o
> Google leva semanas para reindexar. Se o cliente pretende comprar, é melhor comprar agora.
>
> **Redes sociais:** o Google usa os perfis para confirmar que a empresa é a mesma. É o campo de
> SEO mais barato que existe — dois minutos de trabalho.
>
> **Registro do conselho:** se a profissão tem conselho, exibir o número é obrigação. Publicar sem
> é uma infração do cliente com o conselho dele.

## 8. Material que você tem — quanto mais, melhor a página

Marque o que existe. Coloque tudo numa pasta só, sem organizar, chamada **`assets-source/`**, na
raiz do projeto. Esse nome não é sugestão: é a pasta que o pipeline lê e a pasta que fica fora do
repositório, para o material cru do cliente não ir parar no GitHub.

- [ ] Logo — **na maior resolução possível.** Se existir arquivo `.svg`, `.ai`, `.eps` ou `.pdf`,
      esse é o certo. Logo baixado do Instagram costuma ser pequeno demais e não serve.
- [ ] Fotos da fachada e da entrada
- [ ] Fotos de dentro (recepção, sala de atendimento, equipamentos)
- [ ] Fotos do trabalho sendo feito — **estas são as mais valiosas e as mais esquecidas**
- [ ] Fotos da equipe
- [ ] Posts do Instagram — o arquivo original, não print de tela
- [ ] Material impresso: cartão de visita, folder, cardápio, adesivo
- [ ] Vídeos, mesmo curtos, mesmo feitos no celular
- [ ] Prints de conversa ou avaliação (só como informação — não vão para o site)

### Sobre as fotos

**Traga mesmo as feias.** O tratamento é nosso. Foto sem graça de um lugar que existe vale mais
que uma imagem gerada por computador de um lugar que não existe — e o visitante percebe a
diferença mesmo sem saber explicar.

**Não traga:** foto com marca d'água de fotógrafo ou de banco de imagem, foto que o cliente pegou
no Google, foto com a marca de um concorrente aparecendo, foto de cliente/paciente identificável
sem autorização. Nenhuma dessas pode ser publicada.

**Nomeie os arquivos** com o que aparece na foto: `fachada-entrada.jpg`, `banho-e-tosa-1.jpg`.
Nome ruim (`IMG_2049.jpg`) não impede nada, mas nome bom acelera.

## 9. Gosto e referência — opcional, mas economiza retrabalho

| Campo | Exemplo preenchido | Sua resposta |
|---|---|---|
| Sites que o cliente admira | `linear.app` | |
| Concorrentes que ele acha bons | `nome do concorrente + site` | |
| O que ele **odeia** | `Azul. E foto de cachorro com roupinha.` | |
| Alguma cor ou imagem proibida | `Vermelho, lembra sangue` | |
| Sensação que a página deve passar | `Segurança e calma. Não quero nada infantil.` | |

> O campo "o que ele odeia" costuma economizar uma rodada inteira de geração de imagem — que é a
> parte mais lenta e mais cara do processo, porque depende de você gerar, olhar e rejeitar.
