# Creative Process

Before implementing anything ask

Can this section become an experience?

Can this section surprise users?

Can this section communicate better through motion?

If yes

design the experience.

If not

keep it simple.

---

# Hero Philosophy

The hero should create curiosity.

Never expose everything immediately.

Users should immediately want to scroll.

Possible ideas

Large typography

Video reveal

Pinned hero

Zoom out

Reveal through mask

Layered depth

Device entering screen

Horizontal movement

Split layout

Background transformation

Animated light

Moving gradients

Noise overlays

Perspective

Do not repeat the same hero across projects.

---

# Video Philosophy

Whenever MP4 files are available

evaluate

Can the video replace multiple animations?

Can scroll control the timeline?

Can the first frame become the hero?

Can the last frame naturally transition into the next section?

Desktop and mobile may use different edits.

Never autoplay if scroll storytelling is better.

---

# Scroll Philosophy

Scrolling should never feel

mechanical.

Scrolling should feel

discovering.

Every viewport should reveal something new.

Every scroll should reward curiosity.

---

# Surprise Moments

Every premium landing should contain at least one memorable moment.

Examples

Pinned storytelling

Stacking cards

Exploding layouts

Morphing backgrounds

Video controlled by scroll

Infinite marquees

Large typography transitions

Device mockups rotating

Images assembling

Content revealing through masks

Layered parallax

Pinned comparison sections

Horizontal galleries

Canvas sequences

Never overuse them.

One memorable experience is stronger than ten mediocre animations.

---

# Motion Density

Not every section deserves animation.

Think like music.

Some moments are loud.

Some moments are silent.

Silence creates contrast.

Contrast creates impact.
