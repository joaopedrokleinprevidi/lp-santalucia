Think like a designer from:

- Apple
- Linear
- Stripe
- Vercel
- Notion
- Framer

Design interfaces that feel

Simple

Intentional

Professional

# Design Philosophy

Beauty is the result of clarity.

Never decorate problems.

Solve them.

Users should immediately understand

Where they are

What they can do

What is important

What happens next

---

# Visual Hierarchy

Always establish hierarchy using

Size

Spacing

Contrast

Weight

Position

Never rely only on color.

The eye should naturally know where to look first.

---

# Layout

Prefer

Large margins

Consistent spacing

Predictable grids

Strong alignment

Comfortable breathing room

Avoid

Crowded layouts

Random spacing

Misaligned elements

Visual noise

---

# Grid System

Design using consistent grids.

Respect rhythm.

Elements should align naturally.

Avoid arbitrary positioning.

---

# Spacing

Whitespace is a design tool.

More whitespace increases perceived quality.

Use spacing to create hierarchy.

Not empty space.

Every gap should have a purpose.

---

# Typography

Typography communicates hierarchy before users read.

Prefer

Large headlines

Short paragraphs

Comfortable line height

Readable measure

Consistent font weights

Avoid

Tiny text

Huge paragraphs

Multiple font families

Random font weights

Decorative typography

---

# Headlines

Headlines should communicate

Outcome

Purpose

Direction

Avoid

Marketing clichés

Empty adjectives

Buzzwords

---

# Paragraphs

Keep paragraphs short.

One idea per paragraph.

Readable at a glance.

Avoid walls of text.

---

# Color

Color has responsibility.

Use it to

Guide

Highlight

Confirm

Warn

Never use color as decoration.

Accent colors should be rare.

The rarer they are,

the more powerful they become.

---

# Contrast

Important actions deserve stronger contrast.

Secondary actions should remain visible without competing.

Everything cannot be primary.

---

# Components

Every component should answer

Why does this exist?

If the answer is unclear,

remove it.

---

# Buttons

There should usually be

One primary action.

Everything else is secondary.

Avoid multiple competing CTAs.

---

# Cards

Cards should group related information.

Never use cards simply because modern apps use cards.

Use containers intentionally.

---

# Icons

Icons support text.

They do not replace labels.

Avoid icon-only interfaces unless universally understood.

---

# Images

Images should communicate.

Not decorate.

Every illustration,

photo

or screenshot

must reinforce the message.

---

# Motion

Motion supports design.

It never replaces hierarchy.

Interfaces should remain understandable without animation.

Delegate animation decisions to the specialized motion skills.

---

# Information Density

Avoid extremes.

Too little information feels empty.

Too much feels overwhelming.

Balance density.

---

# Visual Rhythm

Alternate

Dense sections

↓

Light sections

↓

Dense

↓

Light

Users should never feel exhausted.

---

# Consistency

Components should behave consistently.

Spacing should remain consistent.

Colors should remain consistent.

Typography should remain consistent.

Consistency builds trust.

---

# Accessibility

Always design for

Contrast

Keyboard navigation

Screen readers

Reduced motion

Readable typography

Accessibility is part of good design.

Not an afterthought.

---

# Mobile First Thinking

Design for touch.

Respect thumb zones.

Increase tap targets.

Reduce unnecessary complexity.

Avoid desktop layouts squeezed into mobile.

---

# Premium Aesthetics

Premium products feel

Quiet

Minimal

Balanced

Confident

Never loud.

Never flashy.

Never overloaded.

Premium interfaces don't need to prove they are premium.

They simply feel that way.
